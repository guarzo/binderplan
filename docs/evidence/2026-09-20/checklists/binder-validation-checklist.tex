\section{8\quad Holding-box photography}
\sub{Prepare}
\begin{itemize}
\item Keep existing EDGE, REDUNDANT, HERITAGE, FUTURE SELF and RELEASE groups separate. Label unsorted cards \textbf{unsorted}; no need to pre-classify.
\item Mark cards unavailable for placement: released, promised, reserved for another collection, etc.
\item Identify any of the four departed cards on page 1.
\end{itemize}
\sub{Each batch}
\begin{itemize}
\item Use a consistent grid, \textbf{6--9 cards per photo}, fewer if text is too small. No overlapping card faces.
\item Include a paper label: e.g. EDGE-01 or UNSORTED-03. Keep order stable for batch + row + column references.
\item Show full fronts, straight on, in even light without glare; add artwork/number close-ups as needed.
\item Label by card name and printed number where legible; batch + pocket distinguishes otherwise similar cards.
\item Show separate copies separately. Note hard-to-see foil, stamp and language differences.
\end{itemize}
\smallnote{Do not remove protective sleeves if that risks damage.}
\sub{Send with the photos}
\begin{itemize}
\item Photo date; sections included and any omissions.
\item Cards you particularly want considered; personal keepers even without a thematic home.
\item Checklist decisions, name/number-labelled close-ups, batch-labelled holding photos and changed binder pages.
\item \textbf{Separate list of moves actually completed}, with dates and after photos.
\end{itemize}
