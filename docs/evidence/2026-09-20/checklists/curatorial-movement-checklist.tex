\section{Registration and recording}
For every incoming card:
\begin{itemize}
\item Search the registry once more before assigning an ID.
\item Preserve an existing ID if the exact physical card already has one.
\item Otherwise assign the next species counter under registry conventions.
\item Record printed language, set and number from the physical footer; mark uncertainty honestly.
\item Preserve the holding photograph as provenance.
\end{itemize}

After all physical moves:
\begin{itemize}
\item Photograph On the Attack, Awakened Power p1 and Legendary Bearing p2.
\item Confirm each affected page has nine occupied pockets.
\item Append only movements actually completed to docs/ledger.md.
\item Record holding destinations where known; never equate binder removal with release.
\item Run the registry checker after adding incoming identities.
\end{itemize}
