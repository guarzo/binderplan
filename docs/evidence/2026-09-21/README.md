- `blastoise-02` is confirmed as a Chinese-language Blastoise VMAX using the SWSH103 artwork, but its exact Chinese set and collector number remain unresolved. English SWSH103 metadata must not be copied onto it.
- Other incoming identities use the set/number recorded in the holding export and visually matched artwork. Because those footers were not legible in the preserved photographs, their registry confidence remains `uncertain` until checked in hand.

No release is established. Cards marked EDGE or HERITAGE remain held outside the thematic binder.
